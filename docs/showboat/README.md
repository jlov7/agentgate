# Executable Demos With Showboat

These docs are generated by [Showboat](https://github.com/simonw/showboat) so they are readable and executable.

## What you get

- **Release Readiness Proof**: runs release gates and summarizes doctor output.
- **Frontend Excellence Proof**: runs the docs frontend gate and summarizes cross-browser results.

## Generated demos

- [Release Readiness Proof](release-readiness.md)
- [Frontend Excellence Proof](frontend-excellence.md)

## Regenerate demos

```bash
make showboat-demos
```

Force fresh gate runs before regenerating (slower, but fully current proof):

```bash
SHOWBOAT_REFRESH_GATES=1 make showboat-demos
```

## Verify demos

```bash
make showboat-verify
```

The proof commands are intentionally real and may take a few minutes because they run the same gate scripts used for release readiness.
